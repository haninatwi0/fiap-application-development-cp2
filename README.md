# FIAP Application Development – CP2

## Institutional Website for a Technology Startup

This project was developed as part of the **Application Development** course at FIAP.

The objective of this Checkpoint was to develop an institutional website for a technology startup, applying HTML and CSS concepts studied during the course.

## Technologies

* HTML5
* CSS3

## Project Features

The website includes:

* Header with company name/logo
* Navigation menu
* Home section
* Company information
* Mission, vision and values
* Solutions and services
* Service cards
* Plans/services table
* Contact and budget form
* Footer with contact information and links
* CSS styling and visual identity
* Box Model and organized page layout
